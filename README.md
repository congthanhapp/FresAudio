# 🎵 FresAudio

Ứng dụng phát nhạc offline trên máy tính Windows, hỗ trợ tải nhạc từ YouTube, SoundCloud, Spotify và TikTok về máy.

</div>

---

## ✨ Tính năng chính

- **Phát nhạc offline:** Hỗ trợ các định dạng âm thanh phổ biến như MP3, FLAC, WAV, AAC, M4A...
- **Tải nhạc về máy:** Hỗ trợ tải bài hát từ YouTube, SoundCloud, Spotify và TikTok.
- **Quản lý danh sách phát:** Tạo playlist, lưu bài hát yêu thích và duyệt nhạc theo thư mục.

---

## 🚀 Tải về & Cài đặt

1. Vào mục [**Releases**](https://github.com/congthanhapp/FresAudio/releases).
2. Tải về file **`FresAudio_Setup.exe`**.
3. Chạy file vừa tải để tiến hành cài đặt.
